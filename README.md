# Holy Stocks Screener (Testlauf)

Statische Seite: Wyckoff-Akkumulations-Board, Streudiagramm und Detailcharts. Enthält nur die Seite und die erzeugten JSON-Daten (`data/`).
Charts: [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) v4.2 (Apache 2.0, `lwc.js`).
Keine Anlageberatung.
